# Bank Management System (JavaFX)

A GUI-based Bank Management System built using Java, JavaFX, and Maven.

## Features
- User and admin login
- Account creation and profile management
- Deposit and withdrawal transactions
- Transaction history
- JavaFX GUI with CSS styling

## Technologies Used
- Java
- JavaFX
- Maven
- CSS

## How to Run
1. Clone the repository
2. Open the project in VS Code or IntelliJ
3. Run Main.java or use:
   mvn javafx:run
